# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for DistroCommerce.

An ADR documents a significant architectural decision: the context, the options considered, the decision made, and its consequences.

## Index

| ADR                                                           | Title                                     | Status   |
|---------------------------------------------------------------|-------------------------------------------|----------|
| [ADR-001](adr-001-clean-architecture-domain-driven-design.md) | Clean Architecture + Domain-Driven Design | Accepted |
| [ADR-002](adr-002-phase-based-graceful-shutdown.md)           | Phase-Based Graceful Shutdown             | Accepted |

## Format

Each ADR follows the structure:
- **Status** — Proposed / Accepted / Deprecated / Superseded
- **Context** — What problem or situation prompted this decision
- **Decision** — What was decided and why
- **Consequences** — What becomes easier or harder as a result
